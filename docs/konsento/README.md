# Konsento — Documentació

Aquest projecte és ara un **repositori independent**: `github.com/112books/konsento`
(privat durant el desenvolupament; candidat a programari lliure AGPL).

La documentació canònica (prototip, formularis, i18n, disseny UI, manuals i
desplegament) viu a `docs/` dins d'aquell repo:

- **Repo:** https://github.com/112books/konsento
- **Docs:** https://github.com/112books/konsento/tree/main/docs

**Context:** eina de governança lliure i lleugera d'assemblees i comissions per a
espais autogestionats, nascuda dins de `naubostik-web-v3`.
